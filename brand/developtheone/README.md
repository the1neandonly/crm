# DevelopTheOne — `{ DTO }` — Brand Identity Kit

Digital marketing agency · **Become the one.** · *Devenez la référence.* · `{ develop: "the one" }`

The logo is a faithful vector rebuild of the original DevelopTheOne logo, so the brand stays exactly the one the community already knows:
- the **`{ }` braces** (code)
- the **D with the clicking cursor** (action)
- the gray **T** linked by the **cable** (connection)
- the **O with its inner ring and two nodes** (community)
- **"DevelopTheOne"** in Montserrat Bold, DTO Blue

Start with the guidelines (58 pages each):
- **`DevelopTheOne-Charte-Graphique-FR.pdf`**: French edition
- **`DevelopTheOne-Brand-Guidelines.pdf`**: English edition

## Colours
| Name | HEX | Use |
|---|---|---|
| DTO Blue | `#0F66B6` | Primary: the wordmark blue |
| Code Black | `#0A0B0D` | The mark, dark surfaces, body text |
| White | `#FFFFFF` | The cursor, light surfaces |
| Cursor Gray | `#A5A8AA` | The T outline (≈ Pantone Cool Gray 6 C) |
| Sky Blue | `#4AA3F0` | Highlight on dark surfaces only |
| DTO Gradient | `#4AA3F0 → #0F66B6 → #0A3D73` | 135° |

## Fonts (free, OFL, included in `fonts/`)
Montserrat (titles and wordmark) · Inter (text) · JetBrains Mono (code accents) · Cairo (Arabic)

## Logo versions (in `logo/`, as SVG · PNG · JPG · WEBP · PDF · EPS)
- `horizontal`: primary, as the original
- `stacked`
- `symbol`: the `{DTO}` mark alone
- `icon`: `{D}` with the cursor, for avatars, favicons and apps
- `horizontal-compact`
- `wordmark-plain`: DevelopTheOne alone
- `wordmark`: DevelopTheOne + MARKETING AGENCY

Colours: `color` (original, on white) · `color-dark` · `on-violet` (on DTO Blue) · `black` · `white`

## Folders
Same structure as the Bayna kit:

| Folder | Contents |
|---|---|
| `icons/` | Favicons, app icons, avatars and service icons |
| `patterns/` | Braces, `</>`, cursors, nodes and waves |
| `social/` | Social templates, plus editable PPTX |
| `banners/` | Social headers, web banners, ads, large format |
| `video/` | Logo animations (MP4, MOV/WebM alpha, GIF) |
| `print/` | Print files with bleed |
| `presentation/` | Editable PowerPoint |
| `mockups/` | 14 mockup scenes |
| `ready-to-use/` | Everything sorted by platform and usage |
