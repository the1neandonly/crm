# Bayna Agency — Brand Identity Kit

Marketing & communication agency · Oran, Algérie
**Tagline:** *Proof, by design.* / *La preuve, par le design.*

Start with **`Bayna-Agency-Brand-Guidelines.pdf`** (charte graphique, 17 pages). It covers the concept, construction, logo suite, clear space, colours, typography, charts and applications.

## The logo
A lowercase **b** built from the three shapes of a marketing report: a **bar** (growth), a **pie chart** (audience/data) and its highlighted **lime slice** (the insight). The wordmark is set in Syne Bold.

## Folder map
| Folder | Contents |
|---|---|
| `logo/svg` | Master vector files for web and editing |
| `logo/pdf`, `logo/eps` | Vector files for print shops and Illustrator |
| `logo/png/<lockup>` | Transparent PNGs in 3 sizes each |
| `logo/jpg` | Logos on their background colour, 300 dpi |
| `icons/` | `favicon.ico`, favicons, apple-touch and android icons, app icons, profile avatars |
| `social/` | LinkedIn, Facebook, X headers, Instagram posts and story (PNG + JPG) |
| `stationery/` | Business card print PDF (85×55 mm + 3 mm bleed), A4 letterhead PDF, email signature |
| `source/` | Python/Playwright scripts that regenerate every file |

**Lockups:** `horizontal` (primary), `horizontal-compact` (without AGENCY, for small sizes), `stacked`, `icon`, `wordmark`.
**Colourways:** `color` (on light), `color-dark` (on Ink), `on-violet` (on violet/gradient), `on-lime` (icon only), `black`, `white`.

## Before printing
- Name, phone, email, web address, RC and NIF on the stationery are **placeholders**. Replace them with your real details.
- Pantone references are the nearest matches. Confirm them on a physical swatch book and ask for a press proof.

## Fonts (free, Google Fonts, OFL)
Syne (titles) · Manrope (text) · Readex Pro (Arabic). The logo files contain outlined text, so you don't need the fonts to use them.
